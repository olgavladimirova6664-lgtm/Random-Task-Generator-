# Random-Task-Generator
Владимирова Ольга
Как запустить программу:
Сохраните код в файл main.py.
Убедитесь, что у вас установлен Python (версия 3.6+).
Откройте терминал или командную строку, перейдите в папку с файлом main.py.
Запустите программу командой: python main.py (или python3 main.py на Linux/macOS).
Что делает программа:
генерирует случайную задачу из предопределённого списка по нажатию кнопки;
отображает историю сгенерированных задач с отметками времени;
позволяет фильтровать историю по категориям («учёба», «спорт», «работа»);
даёт возможность добавлять новые задачи с указанием категории;
проверяет, что новая задача не пустая;
сохраняет историю в файл history.json и загружает её при следующем запуске.
